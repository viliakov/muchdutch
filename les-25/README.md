## Грамматика

### Когда используем imperfectum

Imperfectum описывает прошлую ситуацию, привычку или события в рассказе:

- Vroeger woonde ik in Utrecht. — Раньше я жил в Утрехте.
- Mijn vader kookte elke avond. — Мой отец готовил каждый вечер.
- Het was koud. Ik wachtte op de bus. — Было холодно. Я ждал автобус.
- Ik opende de deur en pakte mijn jas. — Я открыл дверь и взял куртку.

Название «прошедшее незавершённое время» на скриншоте условное: **imperfectum может описывать и завершённые события**. Оно не совпадает с русским несовершенным видом.

### Связь с perfectum из урока 24

- Ik heb gisteren gewerkt. — Сообщение о прошедшем действии.
- Gisteren werkte ik thuis. Het was rustig. — Описание прошлой ситуации.

Оба варианта могут быть правильными: выбор зависит от контекста. Слова `gisteren`, `vroeger`, `geleden` помогают указать время, но не задают его автоматически. Для состояний с `zijn / hebben` очень обычны `was / waren`, `had / hadden`: `Ik was ziek. Ik had koorts.` В дополнительной работе тренируем imperfectum там, где это прямо указано.

### Регулярные глаголы

1. Получите основу с правильным написанием: `werken → werk`, `wonen → woon`, `maken → maak`.
2. Выберите окончание. Если перед `-en` в инфинитиве стоит глухой согласный `t, k, f, s, ch, p` (также звук /ʃ/, например в заимствованиях), используйте `-te / -ten`; в остальных обычных случаях — `-de / -den`.
3. Для `ik, jij, hij, zij, het, u` используйте единственное число. Для `wij, jullie, zij` («они») — множественное.

| Инфинитив | Единственное число | Множественное число |
| --- | --- | --- |
| werken | werkte | werkten |
| koken | kookte | kookten |
| fietsen | fietste | fietsten |
| maken | maakte | maakten |
| wachten | wachtte | wachtten |
| wonen | woonde | woonden |
| leren | leerde | leerden |
| spelen | speelde | speelden |
| luisteren | luisterde | luisterden |
| betalen | betaalde | betaalden |
| reizen | reisde | reisden |
| leven | leefde | leefden |

**Ловушка:** `reizen → reisde`, `leven → leefde`. В ik-форме пишем `s / f`, но при выборе окончания учитываем `z / v` инфинитива. Правило относится к регулярным глаголам, а не ко всем глаголам на `-zen / -ven`: `lezen → las`, `geven → gaf` — неправильные.

Если основа заканчивается на `t / d`, прибавляем окончание полностью: `wacht + te → wachtte`, `antwoord + de → antwoordde`. Поэтому `wij wachten` — настоящее, `wij wachtten` — прошедшее. В отличие от perfectum, здесь не добавляем `ge-` и вспомогательный глагол.

### Неправильные формы: знакомые слова

Вначале выучите `zijn` и `hebben`; остальные используйте как справочник к упражнениям. Это новые формы уже знакомых глаголов.

| Инфинитив | Единственное число | Множественное число |
| --- | --- | --- |
| zijn | was | waren |
| hebben | had | hadden |
| gaan | ging | gingen |
| komen | kwam | kwamen |
| doen | deed | deden |
| eten | at | aten |
| drinken | dronk | dronken |
| lezen | las | lazen |
| schrijven | schreef | schreven |
| zien | zag | zagen |
| geven | gaf | gaven |
| nemen | nam | namen |
| kopen | kocht | kochten |
| slapen | sliep | sliepen |
| zitten | zat | zaten |
| beginnen | begon | begonnen |
| blijven | bleef | bleven |
| verkopen | verkocht | verkochten |

Модальные глаголы в этой домашней работе остаются в знакомом настоящем времени. Их формы прошедшего времени пока не заучиваем.

### Порядок слов

- Ik werkte gisteren thuis. — Обычный порядок.
- Gisteren werkte ik thuis. — После обстоятельства сначала глагол, затем подлежащее.
- Werkte je gisteren thuis? — Общий вопрос.
- Waar werkte je vroeger? — Вопрос со словом `waar`.
- Ik werkte gisteren niet. / Ik had geen fiets. — Отрицание.

В imperfectum форма с `jij / je` в вопросе сохраняется: `jij werkte → werkte jij?`, `jij had → had jij?`.

Разделяемые глаголы: `Ik ruimde mijn kamer op.`; `Zij droogde zich af.` Возвратные местоимения уже знакомы: `Ik voelde me goed. Wij maakten ons klaar.` Для регулярных `voelen, kammen, afdrogen, klaarmaken, herinneren, ergeren, concentreren, aanmelden, omdraaien` применяем обычное правило окончаний.

### Toen: «тогда» и «когда» в прошлом

- Toen woonde ik in Utrecht. — Тогда я жил в Утрехте. Здесь `toen` — обстоятельство, после него инверсия.
- Toen ik klein was, woonde ik in Utrecht. — Когда я был маленьким, я жил в Утрехте.

Во втором примере `toen` вводит придаточное: `toen + подлежащее + остальные слова + глагол`. После всего придаточного главная часть начинается с глагола: `…, woonde ik…`. Пока используем короткие предложения с одним глаголом в каждой части. Для повторяющегося «всякий раз, когда» не переносите эту модель автоматически: это отдельная тема.

### Указатели времени со скриншота

| Выражение | Значение | Простой пример |
| --- | --- | --- |
| vroeger | раньше | Vroeger fietste ik naar school. |
| lang geleden | давно | Lang geleden woonde ik hier. |
| … jaar geleden | … лет назад | Twee jaar geleden werkte ik daar. |
| in het jaar … | в … году | In het jaar 2020 woonde ik hier. |
| in de jaren … | в …-е годы | In de jaren negentig woonde mijn oma hier. |
| in de … eeuw | в … веке | In de twintigste eeuw leefde mijn oma. |
| toen | тогда; когда в прошлом | Toen was ik klein. |
| van … tot … | с … до … | Van twee tot vier wachtte ik op de bus. |

`De eeuw` — век: дано только для понимания таблицы источника, не входит в активный словарь и задания этого урока. Историческую лексику со скриншота не заучиваем. Упоминание войны на скриншоте не используем как историческую справку.

## Темы лексики

Всего четыре новые активные единицы: **vroeger** — раньше; **toen** — тогда / когда в прошлом; **geleden** — назад (о времени); **het imperfectum** — простое прошедшее время. `Lang geleden` связано со знакомой фразой `dat is lang geleden` из урока 11. Новые единицы внесены в [общий словарь](../WORDS.md).

Повторяем слова из предыдущих уроков: семья, комнаты, еда, транспорт, одежда, школа, аптека и повседневные действия. Новые формы знакомых глаголов не считаются новыми словами.

## Произношение

В окончаниях `-te / -de` гласный безударный: /ə/. Двойные `tt / dd` в `wachtte / antwoordde` важны на письме; не нужно произносить их как две отдельные согласные. Отдельного аудиоматериала нет.

## Аудирование и устная речь

Для самостоятельного повторения прочитайте примеры и пары `werk — werkte`, `woon — woonde`, `ben — was`. На скриншотах нет записи для аудирования.

## Полезные примеры

1. Vroeger woonden wij in een klein huis. — Раньше мы жили в маленьком доме.
2. Gisteren wachtte ik op de bus. — Вчера я ждал автобус.
3. Had je toen een fiets? — У тебя тогда был велосипед?
4. De kinderen waren thuis. — Дети были дома.
5. Toen ik ziek was, belde ik de huisarts. — Когда я болел, я звонил семейному врачу.
6. Twee jaar geleden leerde ik Nederlands op school. — Два года назад я учил нидерландский в школе.
