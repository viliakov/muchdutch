## Грамматика

### Когда используется perfectum

Обычно — когда сообщаем о совершившемся действии или результате:

- Ik heb het boek gelezen. — Я прочитал книгу.
- Ik ben mijn sleutel vergeten. Nu kan ik niet binnenkomen. — Я забыл ключ. Теперь не могу попасть внутрь.
- Hij is ziek geworden. — Он заболел.

Подсказки: `al` — уже; `nog niet` — ещё не; `net` — только что; `al eens` — уже когда-либо, уже раз. Сами по себе эти слова не определяют время. Действие, продолжающееся сейчас, может требовать настоящего времени: `Ik woon al vier jaar in Amsterdam.` — Я живу в Амстердаме уже четыре года.

### Формула и порядок слов

**Подлежащее + hebben / zijn в настоящем времени + остальные слова + voltooid deelwoord.**

| Подлежащее | hebben | zijn |
| --- | --- | --- |
| ik | heb | ben |
| jij / je | hebt | bent |
| hij / zij / het | heeft | is |
| u | hebt | bent |
| wij / jullie / zij | hebben | zijn |

В заданиях используем `u hebt / u bent`; для hebben также употребляется `u heeft`.

- Ik heb gisteren medicijnen gehaald.
- Gisteren heb ik medicijnen gehaald. — Инверсия: спрягаемый глагол остаётся на втором месте.
- Heb je de medicijnen gehaald? — Общий вопрос; у `jij / je` после глагола нет окончания `-t`.
- Waar heb je de medicijnen gehaald? — Вопросительное слово + вспомогательный глагол + подлежащее.
- Ik heb de medicijnen nog niet gehaald.
- Ik heb geen medicijnen gekocht.

### Hebben или zijn

`Hebben` — большинство действий: `Ik heb gewerkt / geslapen / gewandeld.` Возвратные глаголы в изучаемых примерах тоже с hebben: `Ik heb me gewassen.`

`Zijn` — переход в новое состояние и ряд глаголов перемещения: `Hij is ziek geworden.`; `Zij is naar huis gegaan.`; `Wij zijn thuisgekomen.` Также: `Ik ben thuis gebleven.`; `Ik ben bij de huisarts geweest.`

**Не любое движение требует zijn.** Сравните:

- Ik heb twee kilometer gelopen. — Пройденное расстояние, действие.
- Ik ben naar de apotheek gelopen. — Перемещение к определённому месту.
- Wij hebben een uur gefietst. / Wij zijn naar school gefietst.

В этом уроке для «забыть ключ / рецепт» используем `zijn`: `Ik ben het recept vergeten.` У vergeten возможен и hebben; не считайте такую форму автоматически ошибочной.

### Регулярное причастие: ge- + основа + -t / -d

1. Определите основу и сохраните нужное написание: `maken → maak`, `wonen → woon`.
2. Для выбора `-t / -d` смотрите на согласный инфинитива перед `-en`: после `s, f, t, k, ch, p` пишем `-t`; иначе обычно `-d`.
3. Добавьте `ge-`, если нет исключения с приставкой.

| Инфинитив | Причастие | Пример |
| --- | --- | --- |
| werken | gewerkt | Ik heb gewerkt. |
| maken | gemaakt | Zij heeft huiswerk gemaakt. |
| wonen | gewoond | Wij hebben daar gewoond. |
| wachten | gewacht | Ik heb gewacht. |
| horen | gehoord | Heb je dat gehoord? |
| leven | geleefd | Hij heeft lang geleefd. |
| reizen | gereisd | Zij is naar Japan gereisd. |

Основа, заканчивающаяся на `t` или `d`, не получает вторую такую букву: `wachten → gewacht`, `antwoorden → geantwoord`. У `leven` и `reizen` ориентируемся на `v / z` инфинитива, хотя в ik-форме получаем `leef / reis`.

### Приставки и неправильные формы

- У глаголов с безударными неотделяемыми приставками `be-, ge-, her-, ver-, ont-, mis-` обычно нет дополнительного `ge-`: `beloven → beloofd`, `gebruiken → gebruikt`, `vertellen → verteld`. Это правило о неотделяемой приставке, а не о любом совпадении первых букв.
- У разделяемых глаголов `ge-` стоит между приставкой и основой: `opsturen → opgestuurd`, `innemen → ingenomen`, `afwassen → afgewassen`.
- Неправильные формы учим отдельно: `gelezen`, `gezien`, `genomen` нельзя получить по правилу `-t / -d`.

| Инфинитив | Причастие | Вспомогательный глагол в примере |
| --- | --- | --- |
| nemen / innemen | genomen / ingenomen | heeft |
| drinken | gedronken | heeft |
| eten | gegeten | heeft |
| lezen | gelezen | heeft |
| zien | gezien | heeft |
| zeggen | gezegd | heeft |
| kopen | gekocht | heeft |
| slapen | geslapen | heeft |
| gaan | gegaan | is |
| komen | gekomen | is |
| worden | geworden | is |
| zijn | geweest | is |
| blijven | gebleven | is |
| vergeten | vergeten | is — в примере с забытым ключом |

Дополнительная опора для домашней работы: знакомые глаголы в новых формах. У следующих форм используйте hebben:

| Инфинитив | Причастие |
| --- | --- |
| betalen / beantwoorden | betaald / beantwoord |
| brengen / meebrengen | gebracht / meegebracht |
| leggen / zetten | gelegd / gezet |
| vinden / helpen | gevonden / geholpen |
| geven / krijgen | gegeven / gekregen |
| sluiten / begrijpen | gesloten / begrepen |
| ontbijten / verkopen | ontbeten / verkocht |
| zich wassen / zich scheren | zich gewassen / zich geschoren |
| zich ontspannen / zich gedragen | zich ontspannen / zich gedragen |

`Zich` здесь — словарная форма: `Ik heb me gewassen`, `Wij hebben ons ontspannen`. Для направления и возвращения: `is naar huis gelopen`, `is naar school gefietst`, `is thuisgekomen`, `is teruggekomen`. Сам глагол `lopen` имеет причастие `gelopen`, `fietsen` — `gefietst`.

С модальными глаголами пока тренируем знакомое настоящее время: `Ik moet de medicijnen halen.` Для сочетания с прошедшим действием используем два простых предложения: `Ik heb de huisarts gebeld en ik moet thuisblijven.`

## Темы лексики

- Лекарства: `de pil`, `de zalf`, `de druppel`, `het doosje`, `innemen`, `smeren`, `de huid`.
- Место покупки: `de apotheek`, `de drogist`; документ: `het recept`.
- Частота: `de keer`, `dagelijks`; количество: `sommige`.
- Простуда: `een loopneus`, `een verstopte neus`, `de hoest`, `lichte koorts`; предметы: `de zakdoek`, `de deken`, `de hoesttablet / de zuigtablet`.
- Новые слова и примечания к знакомым словам внесены в [общий словарь](../WORDS.md).

## Произношение

На скриншоте подчёркнуто: конечное `d` произносится как `t`. По звучанию нельзя надёжно выбрать написание причастия: `gewoond`, `gewerkt`. В `gereisd` написание `d` связано с `z` в `reizen`.

## Аудирование и устная речь

Аудио не приложено. Разминка предлагает обсудить: `Ben jij vaak verkouden?`, `Welke klachten heb je?`, `Hoe kan je jezelf helpen?`, `Welke tips kan je geven aan iemand die verkouden is?` Это вопросы из источника для беседы, не задания дополнительной письменной работы.

## Полезные примеры

1. Ik heb gisteren het recept opgehaald. — Я вчера забрал рецепт.
2. Heb je de pil al ingenomen? — Ты уже принял таблетку?
3. Zij heeft de zalf op haar huid gesmeerd. — Она нанесла мазь на кожу.
4. Wij zijn naar de apotheek gegaan. — Мы сходили в аптеку.
5. Ik heb me vandaag beter gevoeld. — Сегодня я чувствовал себя лучше.
6. De tandarts heeft het gaatje gevuld. — Стоматолог запломбировал зуб.
