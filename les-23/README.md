## Грамматика

### Инструкция тремя способами

| Способ | Пример | Значение |
| --- | --- | --- |
| Просьба с willen / kunnen | Wil je je handen wassen? | Помоешь руки? |
| Необходимость с moeten | Je moet je handen wassen. | Тебе нужно помыть руки. |
| Повелительное наклонение | Was je handen! | Помой руки! |

`Je moet` звучит более настойчиво, чем просьба. Для мягкого совета возможно `Je kunt…`. После модального глагола основной глагол стоит в конце в инфинитиве: `Jullie moeten op tijd komen.`

### Повелительное наклонение — imperatief

В обычной короткой инструкции подлежащего нет. Начинаем с основы глагола, обычно совпадающей с формой `ik`:

| Инфинитив | Инструкция |
| --- | --- |
| bellen | Bel me vanavond! |
| helpen | Help me! |
| lezen | Lees eerst de vragen. |
| beantwoorden | Beantwoord daarna de vragen. |
| gaan | Ga zitten! |
| komen | Kom op tijd! |
| sluiten | Sluit de deur! |
| zijn | Wees rustig! |

`Zijn → wees` — исключение. Форма команды обычно одинакова при обращении к одному человеку и к группе: `Luister!` «Слушай!» / «Слушайте!». Слова `eerst`, `dan`, `daarna` в изучаемой модели идут после глагола: `Lees eerst de tekst.`

Разделяемый глагол: `Ruim je kamer op!` Возвратный: `Concentreer je op de les!` Отрицательная команда: `Praat niet!` / `Maak geen lawaai!`

### Возвратные местоимения

| Подлежащее | Местоимение | Пример |
| --- | --- | --- |
| ik | me | Ik kam me. |
| jij / je | je | Jij ontspant je. |
| hij / zij / het | zich | Hij droogt zich af. |
| u | zich (также u) | U kunt zich inschrijven. |
| wij / we | ons | Wij maken ons klaar. |
| jullie | je | Jullie moeten je goed gedragen. |
| zij / ze — они | zich | Zij draaien zich om. |

- Инверсия: `Elke ochtend kam ik me.`
- Вопрос: `Ontspan je je na school?` Два `je` выполняют разные роли: подлежащее и возвратное местоимение.
- Модальный глагол: `Ik moet me goed concentreren op de les.`
- Разделяемый глагол: `Sara maakt zich klaar voor haar werk.`
- С инфинитивом приставка не отделяется: `We gaan ons inschrijven voor de cursus.`
- Устойчивое выражение: `Je moet je geen zorgen maken.`

### Как описать самочувствие

- `Ik heb buikpijn.` — У меня болит живот.
- `Ik heb pijn in mijn buik.` — У меня боль в животе.
- `Ik heb last van mijn buik.` — Меня беспокоит живот.

`Last hebben van` шире, чем «болеть»: `Ik heb last van het lawaai.` Названия симптомов обычно употребляются без артикля: `hoofdpijn hebben`, `koorts hebben`, `griep hebben`. Другие конструкции: `een wond hebben`, `een gebroken arm hebben`, `verkouden zijn`.

`Buikpijn` — боль в животе в целом; `maagpijn` — боль в желудке. `De kies` — коренной зуб; `de tand` — зуб.

### Как часто?

`Nooit` — никогда; `bijna nooit` — почти никогда; `soms` — иногда; `vaak` — часто; `meestal` — обычно, в большинстве случаев.

- `Ik sport vaak.`
- `Meestal drink ik water bij het eten.`
- `Ik blijf bijna nooit lang op.`
- `Hoe vaak poets je je tanden?` — Как часто ты чистишь зубы?

## Произношение

Отдельного фонетического блока на скриншотах нет. Для повторения: `ij` в `pijn` — дифтонг /ɛi/; `oe` в `hoesten` — /u/; `ui` в `buik` — /œy/. В `kies` гласный /i/. Сравните `kies` (зуб) и `ik kies` (я выбираю): произношение совпадает.

## Аудирование и устная речь

На скриншоте указан файл `5.4. Bij de tandarts.m4a`; само аудио не приложено. По пометкам: у Мелисы болит зуб; стоматолог делает снимок; отмечены два кариозных отверстия вместо трёх; стоматолог их пломбирует. Это чтение пометок, а не проверенная расшифровка.

На круговой схеме предлагается обсудить сон, спорт, еду, воду, время на улице, социальные сети и поздний отход ко сну. Эти открытые вопросы остаются материалом для устной работы; в дополнительной домашней работе используются задания с ключами.

## Полезные примеры

1. `Ik wil graag een afspraak maken met de huisarts.` — Я хочу записаться к семейному врачу.
2. `Kan het eerder?` — Можно раньше?
3. `Ik heb sinds maandag last van mijn keel.` — Горло беспокоит меня с понедельника.
4. `De tandarts kijkt in mijn mond.` — Стоматолог смотрит мне в рот.
5. `Haal het medicijn bij de apotheek.` — Забери лекарство в аптеке.
6. `Lees eerst de tekst en beantwoord daarna de vragen.` — Сначала прочитай текст, затем ответь на вопросы.
7. `Maak je klaar voor school!` — Собирайся в школу!
8. `Gedraag je goed in de klas!` — Веди себя хорошо в классе!

## Неясности в источнике

- Отдельная секция `huiswerk` не обозначена: в `homework.md` собраны видимые упражнения, без утверждения, что преподаватель назначил их на дом.
- Без аудио ответы на аудирование нельзя независимо проверить.
- На рисунке жалоб некоторые жесты неоднозначны; предложенное распределение учитывает список из десяти слов.
- В упражнении на возвратные глаголы для разделяемых форм на скриншоте недостаточно пропусков. В домашней работе добавлены места для приставок.
- Фразы о лечении в исходном задании — материал для языковой тренировки. В ключе используются нейтральные примеры, а не воспроизводятся все бытовые советы из банка слов.
